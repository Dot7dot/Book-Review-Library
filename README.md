# 閱讀心得圖書館

隨身的閱讀心得圖書館。用「書架」像資料夾一樣分類，在書架裡放進一本本書，每本書可以：

1. **拍照或上傳照片**：拍下封面、內頁或劃線的段落，一本書可以存很多張
2. **打字記錄心得**：閱讀心得、喜歡的句子，或任何想記住的事（自動儲存）

線上使用：<https://dot7dot.github.io/Book-Review-Library/>

## 功能

- 新增 / 重新命名 / 刪除書架，八種木質調顏色可選
- 書架裡按右下角 **＋** 新增一本書；什麼都沒寫的空白書會自動移除
- 照片自動壓縮存放在手機裡；點照片可全螢幕瀏覽、左右滑動、設為封面、刪除
- 搜尋所有書架中的書名、作者與心得內容
- 匯出 / 匯入備份檔（JSON，含照片）
- 可加入主畫面當 App 使用，支援離線、深色模式

## 資料存放

所有資料都存放在瀏覽器的 IndexedDB 中，只留在你自己的裝置上，不會上傳到任何伺服器。
換手機或清除瀏覽器資料前，請先用右上角選單的「匯出備份」保存。

技術說明（避免 iPhone Safari 照片遺失）：

- 選完照片會**立刻**把檔案內容讀進記憶體再處理。iOS 選到的檔案是暫存檔，下次選檔時就會被刪除。
- 照片以 `ArrayBuffer` 存放在獨立的 `photos` store；書的文字存在 `books`，修改文字不會重寫照片。
- 新增 / 刪除照片與更新書的照片清單在同一個 transaction 內完成。
- 照片只在顯示時轉成 `blob:` 網址，離開頁面就釋放；放大檢視在頁面內進行，不開新分頁。
- 舊版（v1，照片存成 Blob）的資料會在開啟時自動轉換；讀不到的照片會顯示「無法讀取，請重新上傳」。
- 更新程式時，請同步調高 `sw.js` 的 `CACHE` 版本與 `index.html`、`js/*.js` 內的 `?v=` 版本號。

> iPhone：用 Safari 開啟後，點「分享 → 加入主畫面」，就能像 App 一樣使用。

## 開發

純 HTML / CSS / JavaScript，沒有建置步驟。在專案根目錄啟動任一靜態伺服器即可：

```bash
python3 -m http.server 8000
# 開啟 http://localhost:8000
```

推送到 `main` 後，GitHub Actions 會自動把網站發布到 `gh-pages` 分支（GitHub Pages）。
